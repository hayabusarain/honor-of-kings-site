# スクリーンショット置き場

ゲーム内の正式表記・数値を確認するためのスクリーンショットを置くフォルダです。
撮影 → ここに保存 → チャットで「スクショ入れました」と伝えるだけで、内容を読み取ってサイトへ反映します。

## フォルダの使い分け

| フォルダ | 入れるもの |
|---|---|
| `map/` | マップ、中立モンスター、ボス、ワープポイントなど |
| `heroes/` | ヒーローのスキル説明、ステータス、アイコン |
| `items/` | アイテムの効果説明、アイコン、価格 |
| `spells/` | バトルスペルの効果説明 |
| `arcana/` | アルカナの効果説明 |
| `misc/` | 上記に当てはまらないもの |

## ファイル名のつけ方

**厳密でなくて構いません。** 何のスクショか分かれば十分です。日本語のファイル名でも問題ありません。

良い例:
- `map/空間の精霊.jpg`
- `heroes/趙雲_スキル1.png`
- `items/ヴェノムスタッフ.jpg`

複数枚ある場合は末尾に連番を付けてください（`趙雲_スキル_1.jpg` `趙雲_スキル_2.jpg`）。

## 撮影のコツ

読み取り精度に直結するので、以下を意識していただけると助かります。

1. **文字が潰れていないこと** — 縮小せず、端末の解像度そのままで保存してください
2. **説明文は全体が入っていること** — スクロールで隠れている部分があれば、分割して複数枚に
3. **数値が見える状態で** — スキルレベルによって数値が変わる場合、どのレベルの表示かが分かると確実です
4. 明るさ・傾きは気にしなくて大丈夫です

## 読み取り時の方針

- **推測で埋めません。** 文字が読み取れない箇所は「読めない」と報告し、勝手に補完しません
- 読み取った数値は、サイトの既存データと突き合わせて差分を報告します
- 反映前に「こう直します」という内容をお見せします

# 確認してほしい項目リスト

Web上の情報だけでは裏付けが取れなかった項目です。優先度順に並べています。

## 優先度: 高（サイトに欠落・誤りの疑いがあるもの）

### 1. ワープポイントと、その付近の精霊 `map/`
- [ ] 精霊の正式名称（4Gamerは「空間の精霊」、note.comは「妖精」と表記。ゲーム内表記が不明）
- [ ] クラッシュレーンのどこに出現するか
- [ ] **倒すとワープが使えるようになる仕様の詳細**（倒す前は使えないのか、時間制限はあるか）
- [ ] 出現時間・再出現間隔
- [ ] 撃破時の報酬（ゴールド・経験値）

> 現状サイトには**記載がありません**。マクロガイドには「ワープポイントのクールダウン30秒」とだけ書かれており、
> 精霊を倒す必要があることが説明されていない状態です。
> ワープがクラッシュレーンにあることと、使用に精霊の撃破が必要な点は複数ソースで一致しています。

### 2. ファイアファルコ `map/`
- [ ] 正式名称（4Gamerは「ファイアファルコ」。英語ソースでは "Firehawk" と "Fire Beak" の2つが登場し対応不明）

- [ ] 撃破時の効果と報酬（英語ソースでは Firehawk = 55ゴールド、Fire Beak = 58ゴールドと別物として記載）
- [ ] 出現時間・再出現間隔（英語ソースでは 0:30 出現・4:00 消滅）

> 現状サイトには**記載がありません**。名前が似た monster が複数あり、Webだけでは同定できませんでした。

### 5. ボス関連の数値 `map/` ← **情報源が矛盾。最優先で確認したい**

複数の攻略サイトを調べたところ、以下の点で記述が食い違っていました。
どれが正しいか Web だけでは判断できないため、ゲーム内での確認が必要です。

| 項目 | サイト現在の記載 | 別ソースの記載 | 要確認 |
|---|---|---|---|
| オーバーロードの出現時刻 | 2:00 | **4:00**（note.com） | [ ] |
| タイラントの出現時刻 | 4:00 | 4:00（一致） | [ ] |
| タイラントのバフ効果 | 連鎖稲妻 | **移動速度＋モンスター/ミニオン/ヒーローへの追加ダメージ**（note.com） | [ ] |
| 10分以降の強化版の名称 | シャドウタイラント／シャドウオーバーロード | **ダークタイラント／ダークロード**（note.com） | [ ] |
| ヴァンガードのウェーブ数 | 2ウェーブ | 2ウェーブ（一致） | [ ] |
| シャドウ系の再出現 | 討伐後3分30秒 | 記載なし | [ ] |
| テンペストドラゴンのシールド | 最大HPの20〜50% | 記載なし | [ ] |

> **特に「シャドウ」か「ダーク」か**は、サイト全体で数十箇所使われている用語なので、
> 正しい方に統一する必要があります。ゲーム内のボス撃破時の表示や、
> マップ上のアイコン名が確認できると確実です。
