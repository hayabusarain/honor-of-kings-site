# スクリーンショット置き場

ゲーム内の正式表記・数値を確認するためのスクリーンショットを置くフォルダです。
撮影 → ここに保存 → チャットで「スクショ入れました」と伝えるだけで、内容を読み取ってサイトへ反映します。

## フォルダの使い分け

| フォルダ | 入れるもの |
|---|---|
| `map/` | マップ、中立モンスター、ボス、ワープポイントなど |
| `heroes/` | ヒーローのスキル説明、ステータス、アイコン |
| `items/` | アイテムの効果説明、アイコン、価格 |
| `spells/` | バトルスペルの効果説明 |
| `arcana/` | アルカナの効果説明 |
| `misc/` | 上記に当てはまらないもの |

## ファイル名のつけ方

**厳密でなくて構いません。** 何のスクショか分かれば十分です。日本語のファイル名でも問題ありません。

良い例:
- `map/空間の精霊.jpg`
- `heroes/趙雲_スキル1.png`
- `items/ヴェノムスタッフ.jpg`

複数枚ある場合は末尾に連番を付けてください（`趙雲_スキル_1.jpg` `趙雲_スキル_2.jpg`）。

## 撮影のコツ

読み取り精度に直結するので、以下を意識していただけると助かります。

1. **文字が潰れていないこと** — 縮小せず、端末の解像度そのままで保存してください
2. **説明文は全体が入っていること** — スクロールで隠れている部分があれば、分割して複数枚に
3. **数値が見える状態で** — スキルレベルによって数値が変わる場合、どのレベルの表示かが分かると確実です
4. 明るさ・傾きは気にしなくて大丈夫です

## 読み取り時の方針

- **推測で埋めません。** 文字が読み取れない箇所は「読めない」と報告し、勝手に補完しません
- 読み取った数値は、サイトの既存データと突き合わせて差分を報告します
- 反映前に「こう直します」という内容をお見せします

### 奥義の判定に使う基準

ゲーム内表示から書き起こした `public/data/skills/ja.json` を見て、次で判定する。

1. **レベル表が3段（Lv.1／Lv.2／Lv.3）** — 通常スキルは Lv.1〜6、パッシブは Lv.1/Lv.15
2. **CDが長くMP消費が大きい** — 奥義は CD20秒以上・MP70以上が目安
3. 迷ったらスキル説明文に「奥義」の語が出ていないか探す

この基準で全116体を確認したところ、CAMP と食い違ったのは 176 の1体だけだった。
形態切替型（154 ムーラン・502 タイガー・507 李信）はレベル表では一意に決まらないので、
枠の位置（スキル4があればスキル4、無ければスキル3）で扱っている。
