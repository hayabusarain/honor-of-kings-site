## まず3枚だけお願いします

いきなり全部撮っていただく前に、**1枚に何件写るかを測らせてください。**
アイテム一覧の画面が使えるなら、1枚で10件以上まとめて読める可能性があります。
そうなると総枚数が一桁違ってきます。

以下の3枚を `screenshots/items/` に入れて「テスト撮りました」とだけ伝えてください。

1. **アイテム一覧の画面**（装備を選ぶ画面全体。個別を開かない状態）
2. **アイテムを1つ開いた詳細画面**（効果の説明文が出ている状態）
3. **アルカナの一覧画面**

これを読んで、必要枚数と撮り方を確定してお返しします。

## 読み取りたい項目

「この情報が写っていれば足りる」という一覧です。撮影のときの目安にしてください。

### アイテム（110件）

| 項目 | 現状のサイト | 備考 |
|---|---|---|
| 英語名 | **110件すべて未取得** | 最優先。英語ページに日本語名が出ています |
| 日本語名 | あり | 突き合わせに使います |
| 価格 | あり | 要検証 |
| ステータス | あり | 要検証（`+80 物理攻撃` など） |
| パッシブ効果 | あり | 要検証 |
| アクティブ効果 | 一部 | 要検証 |
| アイコン | 一部欠落 | 下の欠落リスト参照 |

> **なぜ検証が必要か**
> ヒーローのスキルデータは中国版か旧パッチのもので、小喬のクールダウンが
> サイトでは12.5秒、実際は5秒という水準で食い違っていました。
> アイテムも同じ経路で入っているため、数値が合っている保証がありません。

## 撮影のコツ

前回と同じです。

1. **文字が潰れていないこと** — 縮小せず端末の解像度のまま保存してください
2. **説明文の全体が入っていること** — 切れている場合は分割して複数枚に
3. ファイル名は連番のままで構いません。リネームは不要です
4. 明るさ・傾きは気にしなくて大丈夫です

### 前回と同じく、推測では埋めません

読み取れなかった箇所は空欄のまま残し、「どのアイテムの何が読めなかったか」の
一覧をお返しします。誤った数値を載せるのは、載せないことより有害なためです。

## この後の流れ

1. テスト3枚 → 必要枚数を確定してお伝えする
2. 本撮影 → 読み取り、現在のデータと突き合わせ
3. 差分をご報告してから反映
4. **その後で**、アイテム・アルカナ・スペル各ページに解説文を追加

解説文を先に書くと、数値が変わったときに文章ごと書き直しになります。
データを確定させてからのほうが一度で済みます。
